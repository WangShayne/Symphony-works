# Deliver an operational and configuration Dashboard

The V1 Phoenix LiveView Dashboard includes overview and task views; plan, unit, budget, and coordination detail; permission and clarification queues; Automation Projects; model and Runtime configuration; task types and execution profiles; Tracker, source-control, MCP, and webhook integrations; configuration revisions, secrets, audits, and health status. Configuration management and intervention are first-class product capabilities rather than external administration tasks.
